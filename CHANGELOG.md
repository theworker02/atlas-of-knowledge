# Changelog

## 1.1.0 — 2026-08-20

- Published the first explicitly tagged Hugging Face package containing the complete three-size generative LoRA family: small (`distilgpt2`), medium (`gpt2-medium`), and large (`gpt2-large`).
- Added per-model training metadata, parameter counts, validation losses, checkpoints, requirements, and limitation-focused model cards under `models/generative/`.
- Preserved the validated 20,417-record Atlas dataset, deterministic splits, graph exports, provenance metadata, and the transparent classification baselines.

## 1.0.3 — 2026-08-20

- Added the trained discipline and course classification baselines, their metrics, requirements, and model cards directly to the complete Hugging Face Atlas release under `models/`.
- Corrected release metadata to distinguish the 17 dataset courses from the 10 source-catalog entries.

## 1.0.2 — 2026-08-20

- Doubled the deterministic release depth by expanding every validated learning facet from six to twelve distinct instructional units.
- Added diagnostic checks, case analyses, retrieval practice, formal consistency checks, design tasks, and peer-critique protocols while retaining local provenance, prerequisite chains, and schema validation.
- Rebuilt the complete Hugging Face package and added substantive release notes for both the new release and the previous v1.0.0 release.

## 1.0.0 — 2026-08-19

- Expanded the connected, validated release beyond 10,000 records.
- Added granular learning components beneath each explanation, practice, and verification unit.
- Optimized quality processing for one global graph-validation pass and indexed duplicate checks.

## 0.2.0 — 2026-08-19

- Added allowlisted, license-gated course discovery and SQLite registry.
- Added incremental quality reporting, duplicate fingerprints, prerequisite-cycle checks, deterministic release subsets, and graph export.
- Added GitHub Actions validation, protected Hugging Face publishing, GitHub Pages site, governance, policy, and dataset-card documentation.

## 0.1.0 — 2026-08-19

- Established the Atlas of Knowledge V1 data contract and relationship vocabulary.
- Added 15 original, cross-linked anchor concepts across the initial disciplines.
- Added dependency-free validation, regression tests, dataset card, and CC BY 4.0 licensing.
