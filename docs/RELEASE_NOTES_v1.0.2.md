# Atlas of Knowledge v1.0.2

Released 2026-08-20.

## Highlights

- 20,417 validated, connected records across 10 courses and 15 disciplines.
- 40,832 explicit graph edges, with prerequisite and typed related-concept links.
- Deterministic splits: 16,332 training records, 2,066 validation records, and 2,019 test records.
- Twelve instructional units per validated learning facet, expanding the former six-unit layer with diagnostic checks, case analysis, retrieval practice, formal consistency checks, design tasks, and peer-critique protocols.

## Quality and provenance

The release passed schema, edge-resolution, prerequisite-cycle, relationship-vocabulary, duplicate-fingerprint, and quality-report checks. Every generated record retains a parent lineage and a provenance envelope. The expanded records are original Atlas instructional material; they do not reproduce source course text.

## Distribution

GitHub contains the source pipeline, release metadata, and documentation. The complete data package is published on Hugging Face and contains the dataset card, all split and specialized JSONL subsets, graph export, build metadata, schema, license, citation, and methodology documentation.
